## Shared release checklist for every project
- [ ] Project scope and acceptance criteria confirmed
- [ ] Source repository connected/backed up
- [ ] Agent instruction files and project docs present
- [ ] TODO/backlog tracked with P0/P1/P2
- [ ] Core UX works on mobile, tablet and desktop
- [ ] No fake production metrics, reviews, or user data
- [ ] Auth/roles/permissions tested
- [ ] Backend/data persistence and migrations verified
- [ ] Secrets never committed; env template created
- [ ] Input validation, rate limits, error/loading/empty states
- [ ] Accessibility and keyboard navigation checked
- [ ] Unit/integration/e2e tests run
- [ ] Lint/typecheck/build pass
- [ ] Dependency and security audit
- [ ] Deployment configuration, monitoring and rollback documented
- [ ] Production smoke tests
- [ ] Human approval before merge, publish, or production data changes

## Portfolio workflow
1. Confirm each project has a source repo or create/export a backup.
2. Run a **read-only audit** with Codex CLI or OpenCode.
3. Build a verified backlog and identify integrations/credentials needed.
4. Implement one milestone per branch.
5. Test locally; agent reports evidence and blockers.
6. Open PR and review.
7. Merge only after approval.
8. Deploy only after production checklist passes.
